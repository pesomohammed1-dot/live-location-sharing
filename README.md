# مشاركة الموقع بموافقة المستخدم

واجهة ويب عربية لمشاركة الموقع الجغرافي بين جهازين **بعد موافقة صاحب الجهاز**.

## الحالة الحالية
- واجهة الخريطة وأزرار بدء/إيقاف المشاركة موجودة في `index.html`.
- مشاركة الموقع بين جهازين تحتاج إعداد مشروع Firebase خاصاً بمالك المستودع. لا توجد بيانات Firebase في المستودع حالياً، لذلك لن تعمل المزامنة قبل إتمام الإعداد.
- لا تضع مفاتيح خدمة إدارية أو كلمات مرور في ملفات الموقع.

## إعداد Firebase المطلوب
1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com/).
2. أضف تطبيق Web وانسخ إعدادات Firebase Web SDK إلى كائن `firebaseConfig` داخل `index.html`.
3. من Authentication > Sign-in method فعّل **Anonymous**.
4. أنشئ Realtime Database.
5. من Realtime Database > Rules انشر محتوى الملف `database.rules.json`.
6. تأكد أن `databaseURL` في `firebaseConfig` يطابق عنوان قاعدة البيانات التي أنشأتها.

## النشر
من إعدادات المستودع: Settings > Pages > Deploy from a branch > `main` > `/(root)` > Save.

بعد اكتمال النشر، افتح رابط GitHub Pages. صاحب الموقع يضغط بنفسه على «ابدأ مشاركة موقعي» ويمنح إذن الموقع. يرسل رابط المشاهدة السري إلى الشخص الذي اختاره. يمكنه إيقاف المشاركة في أي وقت.

## ملاحظات الخصوصية
- لا يبدأ تحديد الموقع إلا بعد ضغط المستخدم على زر المشاركة وموافقة المتصفح.
- رابط المشاهدة يعمل كرمز سري؛ لا تنشره علناً أو تشاركه إلا مع الشخص المقصود.
- قواعد قاعدة البيانات تتطلب تسجيل دخول Firebase مجهولاً وتتحقق من نطاق الإحداثيات.
- هذه نسخة أولية وليست نظاماً عالي الضمان أو بديلاً عن تطبيق أمني متخصص.
