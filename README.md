# مشاركة الموقع بموافقة المستخدم

واجهة ويب عربية لمشاركة الموقع الجغرافي بين جهازين **بعد موافقة صاحب الجهاز**.

## حالة المشروع
- واجهة الخريطة وأزرار بدء/إيقاف المشاركة موجودة في `index.html`.
- مزامنة الموقع بين جهازين تعتمد على Firebase Realtime Database.
- **المشروع غير متصل بقاعدة Firebase بعد**: يجب إنشاء مشروع Firebase مملوك لك وإضافة إعدادات Web App الحقيقية إلى `firebaseConfig` في `index.html`.
- أضفت سير عمل GitHub Actions للنشر التلقائي إلى GitHub Pages عند كل تحديث على فرع `main`.

## إعداد Firebase (مطلوب مرة واحدة)
1. افتح [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعاً.
2. من إعدادات المشروع أضف تطبيق Web وانسخ إعدادات Firebase Web SDK.
3. استبدل القيم التجريبية داخل كائن `firebaseConfig` في `index.html` بالقيم التي يعطيك إياها Firebase، بما فيها `apiKey` و`authDomain` و`databaseURL` و`projectId` و`appId`.
4. من Authentication > Sign-in method فعّل **Anonymous**.
5. أنشئ Realtime Database.
6. من Realtime Database > Rules الصق محتوى `database.rules.json` ثم اضغط Publish.
7. تأكد أن `databaseURL` يطابق عنوان قاعدة البيانات الذي يظهر في Firebase Console.

> إعدادات Firebase Web هي إعدادات عميل وليست مفاتيح خدمة إدارية. لا تضع Service Account JSON أو مفاتيح إدارية أو كلمات مرور في هذا المستودع.

## النشر على GitHub Pages
1. افتح المستودع في GitHub ثم Settings > Pages.
2. في Build and deployment اختر **GitHub Actions** كمصدر النشر.
3. افتح تبويب Actions وتأكد من نجاح سير العمل **Deploy static site to GitHub Pages**. سيُعاد النشر تلقائياً عند كل تحديث على فرع `main`.
4. رابط الموقع يظهر في Settings > Pages بعد اكتمال أول عملية نشر.

## طريقة الاستخدام
1. افتح الموقع المنشور على الهاتف الأول.
2. اضغط بنفسك على «ابدأ مشاركة موقعي» واسمح للمتصفح بالوصول إلى الموقع.
3. أرسل رابط المشاهدة السري إلى الشخص الذي اخترته.
4. يستطيع صاحب الموقع إيقاف المشاركة من زر «إيقاف المشاركة».

## الخصوصية والأمان
- لا يبدأ تحديد الموقع إلا بعد ضغط المستخدم على زر المشاركة وموافقة المتصفح.
- رابط المشاهدة يحتوي على رمز عشوائي طويل؛ لا تنشره علناً أو تشاركه إلا مع الشخص المقصود.
- قواعد قاعدة البيانات تتطلب تسجيل دخول Firebase مجهولاً وتتحقق من نطاق الإحداثيات.
- لأن تسجيل الدخول مجهول، فإن من يحصل على رابط الغرفة يمكنه مشاهدة بياناتها؛ لا تعتبر الرابط بديلاً عن نظام صلاحيات قوي.
- هذه نسخة أولية وليست نظاماً عالي الضمان أو بديلاً عن تطبيق أمني متخصص.
